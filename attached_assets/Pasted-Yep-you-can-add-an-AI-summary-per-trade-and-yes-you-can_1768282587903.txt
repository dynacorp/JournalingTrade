## Can you connect *your* OpenAI API account?

Yes.

**Best practice**: your app backend calls OpenAI with your API key stored in an environment variable/secret manager — not in the browser, not in MT5. ([OpenAI Help Center][1])
Use the OpenAI **Responses API** on your server to generate the summaries. ([OpenAI Platform][2])

### Recommended flow

1. MT5 posts trade → your API
2. API stores trade in DB
3. API triggers “AI summarize trade” job
4. Backend calls OpenAI Responses API
5. Save summary back to DB → shown in UI

### Cost control (important)

* Only summarize **closed trades**
* Add a toggle: “AI summary ON/OFF”
* Use the Usage/Costs endpoints to monitor spend if you want. ([OpenAI Platform][3])
